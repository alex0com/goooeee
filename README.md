# goooeee

A native macOS chat app for local and remote inference servers: llama.cpp, vLLM, mlx_lm,
mlx-vlm, DwarfStar 4, LM Studio, Ollama, and any OpenAI- or Anthropic-compatible API.
goooeee doesn't run models itself. It connects to a server, applies the right per-model
settings, renders markdown, code and thinking blocks, shows speed metrics, and includes a
terminal in each window for launching the server.

Status: planning. See [docs/PLAN.md](docs/PLAN.md).
