# goooeee

A native macOS chat app for local and remote inference servers: llama.cpp, vLLM, mlx_lm,
mlx-vlm, DwarfStar 4, LM Studio, Ollama, and anything else that speaks the OpenAI API (the
default for every engine). The Anthropic API is also supported. goooeee doesn't run models
itself. It connects to a server, applies the right per-model settings, renders markdown, code
and thinking blocks, shows speed metrics, and includes a terminal in each window for launching
the server.

goooeee is distributed as source code only: clone it, open it in Xcode, and run. Build
instructions will be added with the first scaffold.
